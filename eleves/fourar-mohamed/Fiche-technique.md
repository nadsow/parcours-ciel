# Fiche technique : adresse IP

## 1. Définition
Une adresse IP est un numéro qui identifie un appareil sur un réseau.
Exemple : 192.168.1.10
## 2. À quoi ça sert ?
Elle sert à identifier un appareil et à permettre aux appareils de communiquer entre eux sur un réseau ou sur Internet.
## 3. Exemple d’utilisation
Quand un ordinateur se connecte à une box Wi-Fi, la box peut lui donner une adresse IP comme 192.168.1.25.
## 4. Commande / outil / matériel associé
Commande Windows : ipconfig
Commande Linux : ip addr
Matériel : box Internet, routeur, ordinateur, téléphone.
## 5. Ce que j’ai appris
J’ai appris qu’une adresse IP permet d’identifier un appareil sur un réseau. J’ai aussi appris à trouver l’adresse IP d’un ordinateur avec la commande ipconfig.
