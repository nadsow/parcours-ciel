Fiche technique : l’adresse IP
Définition

Une adresse IP est un numéro qui identifie un appareil sur un réseau.

 À quoi ça sert ?

Elle sert à permettre aux appareils de communiquer entre eux.

 Exemple d’utilisation

Par exemple, un ordinateur utilise une adresse IP pour communiquer avec une imprimante.

 Commande / outil / matériel associé

La commande ipconfig permet de voir l’adresse IP d’un ordinateur.

 Ce que j’ai appris

J’ai appris qu’une adresse IP est importante pour communiquer sur un réseau.
