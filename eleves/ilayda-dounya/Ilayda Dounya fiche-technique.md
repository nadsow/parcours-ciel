# Fiche technique : Adresse IP 

## 1. Définition
Une adresse IP (Internet Protocol) est un numéro d'identification unique attribué à chaque appareil (ordinateur, téléphone, imprimante) connecté à un réseau informatique ou à Internet. Elle fonctionne comme une adresse postale pour les ordinateurs.

## 2. À quoi ça sert ?
Elle sert à identifier les appareils sur le réseau et à leur permettre de communiquer entre eux. Grâce à l'adresse IP, les données (pages web, messages, fichiers) savent exactement à quel appareil elles doivent être envoyées.

## 3. Exemple d'utilisation
Quand tu visites un site web ou que tu envoies un message depuis ton téléphone, ton appareil utilise son adresse IP pour demander les informations au serveur, et le serveur utilise cette même adresse pour te renvoyer la réponse. Un exemple d'adresse IP locale classique est `192.168.1.1`.

## 4. Commande / outil / matériel associé
commande :"ipconfig" (sur Windows) ou "ifconfig" / "ip a" (sur Linux) dans le terminal pour afficher l'adresse IP de son ordinateur
materiel : Carte réseau, routeur, switch, câble Ethernet ou Wi-Fi

J'ai appris qu'une adresse IP est indispensable pour qu'un appareil puisse envoyer et recevoir des données sur un réseau, et qu'il existe une commande simple pour connaître celle de sa machine.
