# Fiche technique : [LED]

## 1. Définition
Une LED est un composant qui émet de la lumière lorsqu'un courant électrique le traverse dans le bon sens.
## 2. À quoi ça sert ?
Éclairer efficacement avec peu d'énergie.Afficher un état (voyant marche/arrêt).
## 3. Exemple d’utilisation
Le voyant de veille d'une TV, Les lampes de poche et phares de vélo.
## 4. Commande / outil / matériel associé
Résistance : Obligatoire pour éviter de griller la LED,
Arduino / Pile : Source d'énergie ou de contrôle pour l'allumer.
## 5. Ce que j’ai appris
Sens unique : Une LED a une polarité (anode/cathode) et ne s'allume que si le courant entre du bon côté.
Fragilité : Elle ne régule pas le courant elle-même ; sans résistance, elle grille instantanément.
Polyvalence : Ce n'est pas qu'une ampoule, c'est un indicateur visuel et un outil de communication électronique majeur.
