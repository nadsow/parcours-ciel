# Fiche technique : [ma notion]

## 1. Définition
Le DNS signifie « Domain Name System ». 

## 2. À quoi ça sert ?
Le DNS sert à trouver facilement un site Internet sans avoir besoin de retenir son adresse IP

## 3. Exemple d’utilisation
Quand je tape youtube.com dans mon navigateur, mon ordinateur utilise le DNS pour trouver l’adresse IP du serveur de YouTube.

## 4. Commande / outil / matériel associé
On peut utiliser la commande nslookup pour connaître l’adresse IP associée à un nom de domaine

## 5. Ce que j’ai appris
J’ai appris que le DNS permet de transformer un nom de domaine en adresse IP. Il est très important pour utiliser facilement Internet
