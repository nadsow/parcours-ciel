# Parcours CIEL — Terminale

Bienvenue dans le dépôt commun de la classe de Terminale CIEL.

## Organisation du dépôt

- `TP/` : travaux pratiques
- `ressources/` : ressources pédagogiques
- `documentation/` : documentation technique produite par la classe
- `eleves/` : espaces personnels des élèves

## Règles de travail

1. Avant de commencer à travailler :
   `git pull`

2. Travailler uniquement dans son espace personnel,
   sauf consigne du professeur.

3. Vérifier les modifications :
   `git status`

4. Préparer les fichiers :
   `git add .`

5. Créer un commit explicite :
   `git commit -m "Description de la modification"`

6. Publier :
   `git push`

## Workflow

PULL → TRAVAIL → STATUS → ADD → COMMIT → PUSH

## Important

Ne jamais modifier le travail d'un autre élève sans autorisation.

Ne jamais partager son mot de passe GitHub.
