#Fiche technique : Switch

1. Définition
Un switch (ou commutateur) est un boîtier informatique intelligent qui interconnecte les appareils au sein d'un réseau local (LAN). Il analyse les adresses MAC pour diriger les données uniquement vers l'appareil destinataire

2. À quoi ça sert ?
Relier : Connecter ordinateurs, serveurs et imprimantes entre eux.Fluidifier : Optimiser le trafic réseau et éviter les ralentissements.Sécuriser : Isoler certains flux ou services pour protéger les données.Alimenter : Transmettre de l'énergie à des caméras ou téléphones IP via la technologie PoE.

3. Exemple d’utilisation
Un ordinateur envoie un document à une imprimante réseau. 
Le switch intercepte le fichier et l'envoie exclusivement à l'imprimante, sans encombrer la ligne des autres utilisateurs.

4. Commande / outil / matériel associé
Câbles RJ45 : Les cordons nécessaires pour brancher les appareils sur le switch.
Routeur : L'appareil auquel on connecte le switch pour donner l'accès à Internet.
Commandes réseaux : ping (tester la liaison) et arp -a (voir la table des adresses MAC).
Protocole SSH : Pour configurer le switch à distance de manière sécurisée.

5. Ce que j’ai appris
Intelligence : Le switch cible le bon destinataire grâce aux adresses MAC.
Différence Hub/Routeur : Le hub envoie bêtement les données à tout le monde, tandis que le routeur sert à connecter le réseau local vers l'extérieur (Internet).
